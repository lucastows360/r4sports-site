SITE ACADEMIA R4 SPORTS — PUBLICAÇÃO NO GITHUB PAGES

Conteúdo:
  index.html                 página completa (HTML, CSS e JavaScript no mesmo arquivo)
  .nojekyll                  faz o GitHub Pages servir os arquivos sem processar
  img/logo.png               logo da R4 (também usado como ícone da aba)
  img/panorama-provisoria.jpg capa arrastável provisória (fotos internas)
  img/*.jpg                  fotos da academia usadas nas seções

Como publicar:
  1. Crie um repositório no GitHub (ex.: r4sports).
  2. Envie TODO o conteúdo desta pasta para a raiz do repositório, mantendo a pasta img/.
  3. Settings > Pages > Branch: main / (root) > Save.
  4. O site fica em https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

Para editar (bloco CONFIG no fim do index.html):
  whatsapp   número com DDI+DDD, só dígitos (atual: 5543999733594)
  panorama   salve a panorâmica 360° da fachada como img/fachada-360.jpg e o site troca a capa sozinho
  planos     preencha "preco" de cada plano (ex.: preco:"119,90"); vazio mostra "Valor no WhatsApp"

Para trocar uma foto, substitua o arquivo em img/ mantendo o mesmo nome.
